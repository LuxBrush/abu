# ABUkmarks

Automatically updating bookmarks for webcomics, wikis, blogs, and YouTube.

Tutorial Video:  
[![Tutorial Video](https://img.youtube.com/vi/iq0C_uiF-z0/hqdefault.jpg)](https://www.youtube.com/watch?v=6wigmKGt5hQ)

## Features

- **Auto-updating bookmarks**: When you continue to the next page (Page 2, Page 3, etc.), your ABUkmark updates automatically
- **Works with**:
    - Webcomics
    - Wikis
    - Blogs
    - YouTube (videos and playlists)
    - Google Sheets
- **Convert existing bookmarks** to ABUkmarks
- **Multiple ABUkmarks** for different sections of the same website

## How It Works

1. Create an ABUkmark on Page 1 of your favorite webcomic
2. When you continue to Page 2, your ABUkmark updates to Page 2
3. Later when you open your ABUkmark, you'll continue from where you left off
